# Project Statement

## Project Title
Hospital Management System

## Problem Statement

Hospitals handle information about patients, doctors, appointments, and departments. Managing these records manually can make searching and updating information difficult.

The Hospital Management System provides a simple command-line application for organizing these records and performing common management operations.

## Scope

The project covers:
- Patient record management
- Doctor record management
- Appointment booking and cancellation
- Department information
- Basic hospital reports
- Persistent storage using local files

The project does not attempt to replace a production hospital information system or provide medical diagnosis.

## Target Users

- Reception staff
- Small clinic/hospital administrators
- Students demonstrating Java programming concepts

## High-Level Features

1. Patient CRUD operations
2. Doctor management
3. Appointment management
4. Department listing
5. Reports and statistics
6. Input validation
7. Local persistent storage
